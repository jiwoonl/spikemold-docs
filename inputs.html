Input formats and output meaning#

Use explicit axes and preserve preprocessing with the checkpoint. Compilation and runtime input must describe the same model window.

Data

Layout

Example

2D event / unit-spatial linear input

B,T,C,H,W

(1,4,8,1,1) in the training example.

1D event input

B,T,C,L

(1,2,8,8) in the compile example.

Host integer golden

T,H,W,C

(2,1,4,8) after the compile example’s pooling.

Native dense board output

B,T,C,H,W

Convert explicitly before comparing with T,H,W,C golden.

Application raw events

N,4 as [time,y,x,channel]

Floating timestamp with integer-valued coordinates.

Binary event inputs contain only 0 and 1. Use float32 PyTorch tensors for authoring/training. Saved NumPy runtime input can use an admitted binary dtype; the example helpers validate it explicitly. Direct-current and host analog plans have different contracts and must not be encoded as events implicitly. Temporal T is 1–64 where admitted.

Create and save one event window#

import numpy as np
import torch

events = torch.zeros(1, 2, 8, 8, dtype=torch.float32)  # B,T,C,L
events[0, 0, 0, 2] = 1
np.save("events.npy", events.numpy(), allow_pickle=False)
restored = np.load("events.npy", allow_pickle=False)
assert restored.shape == (1, 2, 8, 8)

For a channels-last sequence T,H,W,C, transpose explicitly with array.transpose(0,3,1,2)[None,...] to obtain B,T,C,H,W. An unbatched 4D array can be ambiguous; do not rely on automatic layout guessing. Check the saved package’s input contract with python -m spikepress.cli inspect model.spm.

Encode raw events explicitly#

After installing the C extension:

import numpy as np
import spikepress

preprocessing = {
    "encoding": "uniform_binary_or", "window_start": 0, "window_end": 3,
    "timesteps": 3, "shape_hwc": [2, 3, 8],
}
raw = np.array([[0,0,0,0], [1,1,2,1]], dtype=np.float64)
encoded = spikepress.encode_events(raw, preprocessing)
assert encoded.shape == (1,3,8,2,3)
assert encoded.sum() == 2

Timestamps use the unit you chose for the window. The interval is half-open: an event at window_end is rejected. Repeated events in one cell/bin combine with OR. Coordinates must be finite, integer-valued and in bounds. No implicit sensor crop, polarity reorder, normalization or out-of-window filtering is performed. The encoding must match training. Use the runnable application example to save these transforms with labels and a head.

What a result means#

Board.run returns decoded spike/terminal mappings, or path-specific results. Resident batched execution can return one mapping per window. A successful call still has only the qualification scope of its selected image and SDK.

spike_count sums events per channel across the window and spatial positions. spike_rate divides that count by T; it can exceed one when multiple spatial positions fire. A spatial/time mean for classification is a different reduction; use the explicit host head. Always supply the declared channel count and T so entirely silent channels remain represented.

Membrane state carries within one forward window and resets between native authoring calls. Prepared board inputs cache an owned input snapshot, not a previous prediction. Each run transfers and executes again. See compatibility for lifetime and profile boundaries.
