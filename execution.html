SNN training and C/PL deployment#

The scope centers on IF/LIF, convolution, linear, pooling and spike readout used in SpikingJelly and snnTorch, together with PyTorch Module/autograd workflows. The compiler checks each operator’s geometry, input domain, timestep, precision and target contract. Directly importing the model APIs of these libraries requires separate implementation.

Runnable CPU examples#

A source checkout, compiler extra, and native extension installed with a C compiler and Python development headers are required. Choose new output paths.

python examples/snn_hybrid.py --output /tmp/spikepress-hybrid-new
python examples/snn_hybrid.py --output /tmp/spikepress-hybrid-int8-new --int8

Each command saves and reloads snn_hybrid.spm and compares it with PyTorch. torch_match is a CPU comparison for the specified input and hardware: NOT_CHECKED. INT8 is opt-in and task accuracy requires separate validation. Existing files are not overwritten. The example does not connect to an FPGA or train.

CPU multi-step training#

The existing SpikePress event layers can select CPU recurrence:

layer.native_multistep = True
spikes = layer(inputs)
loss = criterion(spikes, target)
loss.backward()
print(layer.execution_report)

The installed native C extension is required. It supports first-order surrogate BPTT for float32/float64 and propagates gradients to threshold, input and learnable retention. Reset detach, floor STE and the unused decay gradient at T1 follow the existing path. Higher-order gradients raise an error. Integer training fuses recurrence only when the existing bound proves no saturation; otherwise it uses the existing ordered event-by-event path and records saturation_bound in native_status. CUDA input uses the existing path and records cpu_required.

A single C loop replaces timestep-level Python calls while retaining temporal state dependence. Existing B×T convolution is reused. The single-thread CPU recurrence+loss+backward microbenchmark reports medians of 11 interleaved pairs after 3 warmups:

Training schedule and resumption#

The native recipe entrypoint connects existing training-engine fp32_patience_only and qat_patience_only. Uncapped mode retains the requested minimum epochs; default capped mode retains existing epoch limits. A checkpoint whose previous adapter recorded a smaller minimum may be rejected when resuming with the changed schedule. Resume with the original source and recorded schedule, or start training in a new output. Active producer training follows its frozen source and schedule.

Explicit C host regions#

Default compile() uses the existing native contract. Set allow_host_ops=True to select C host regions. Ordinary float32 models run as f32 and float64 input models retain the f64 path.

prepared, preparation = spikepress.prepare(
    model.eval(), example,
    allow_host_ops=True,
)
program = spikepress.compile(
    prepared, example,
    allow_host_ops=True,
)
print(program.report())
spikepress.save(program, "model.spm")
program = spikepress.load("model.spm")
result = program(example)  # host-only plan
output = result["output"]  # NumPy float32, or float64 for an f64 plan

PyTorch handles authoring, capture and training. Deployment numerical kernels run in C; Python handles fixed graph scheduling, metadata and NumPy buffer passing. With host_precision omitted, float32/bool source selects f32 and float64 selects f64. Automatic mode rejects mixed float32/float64 graphs. Explicit host_precision="float32" or "float64" converts to that precision; validate task accuracy against the original after conversion. float16/bfloat16 and integer model capture are rejected; binary bool input and safe binary counts are supported.

Use a fixed-shape single-input/single-output eval graph. Explicit input_domain="binary" checks 0/1 for every execution input. For hybrid graphs, prepare() observes each native layer’s actual ingress on an isolated copy to bind T. BCHW is T1; BTF/BTCHW and 1d wrapper BTCL use their layer’s time axis. Host-only graph report timesteps is None; per-layer T appears in layers.

Explicit dynamic INT8#

# program is a float32 hybrid plan.
compact = program.quantize_dynamic()
print(compact.report())
spikepress.save(compact, "model-int8.spm")
result = compact(example)

This returns a new plan and changes the numerical representation of host Conv2d/Linear. Weights use symmetric INT8 per output channel; activations use symmetric INT8 per Linear row or Conv BT frame. The range is [-127,127], rounding is half away from zero, and zero point is 0. Scales are f32 and a zero tensor uses scale 1. Only fan-in safe for every INT32 accumulation partial sum is admitted. INT16 neuron state and PL INT4 weights/event-ordered saturation retain the existing contract.

Output and bias are f32. Dequantization applies scale/bias with small double temporaries to avoid intermediate overflow and checks the f32 range before returning. Main operations are INT8 multiplication and INT32 accumulation. Results may differ from the original floating model. quantized_accuracy="NOT_CHECKED" is reported; validate accuracy on representative data before deployment. Per-input dynamic scaling does not replace task accuracy validation.

Weight payload is 1/4 of f32 plus per-channel scales and f32 bias. f32 buffers are 1/2 the size of f64. Input activations remain f32 and INT8 scratch is added, so total peak memory depends on weights and graph lifetimes. Inspect parameter_bytes, live_tensor_and_parameter_bytes and peak_with_int8_scratch_bytes. INT8 activation scratch counts toward the workspace budget; other kernel scratch follows each native limit.

PL operation grouping and reentry#

Up to 24 linearly connected native layers are passed at a time to the existing resident compiler. An admissible chain is grouped into one package to reduce host round trips and STARTs. Splits occur at branches and package geometry/capacity boundaries. Existing policy="efficient" and model_id are passed to each PL island’s compiler call. Inspect pl_islands and starts_per_window in report() for the actual plan.

A bias-free frozen INT4 Conv2d→EventIF T1 pattern on binary BCHW can lower to C binary im2col and the existing K1 PL primitive. Exact weight/threshold conversion, a no-overflow certificate, shape and package capacity checks are all required. If proof fails, use the explicitly permitted C Conv+threshold region. Performance advantages across larger kernels and dilation require separate measurement.

Execute a plan containing PL islands with program(example, board=board) or board.load(program) followed by the existing Board API. Actual device admission follows existing public profile checks. One call is one window and neuron state does not persist across calls. Hybrid batch/stream is currently rejected.

Before execution the artifact schema, reference order, parameter bytes, shape/domain, resident package and memory bounds are checked. max_workspace_bytes defaults to 64 MiB. The report’s live tensor+parameter estimate excludes JSON, PL image, DMA and kernel scratch; per-native-kernel scratch limits also apply.

Installation and example#

python -m pip install -e '.[compiler]'
python examples/snn_hybrid.py --output build/snn-hybrid-demo

The example compares a PyTorch threshold and classifier with C execution before and after saving the package. An installation without the C extension reports the required installation condition when native execution is requested. Use examples/ from a checkout or source distribution.

New f32/INT8 hybrid plans use the .spm.hybrid.v2 envelope. Existing f64 plans remain .spm.hybrid.v1. Existing resident/virtual artifact loaders remain in use. Upgrade installations that do not support the new schema before reloading. To replace an artifact, export to a separate path and preserve the original.

Hardware verification scope#

The INT16 state kernel has scalar and ARM NEON dispatch. It preserves time/event order and vectorizes independent state lanes. Current verification covers host scalar, C sanitizer and ARM cross-assembly. ARM execution and board latency remain unverified. Native DMA wait uses a C monotonic loop, with a Python callback for PYNQ status observation and the existing driver for final handling.

The runtime verifies the image and package at load time. Use binary event windows for FPGA segments. Model and input qualification applies to recorded bytes; see measured performance. J/input, J/spike and total latency require compatible measured calibration.

Compact 1D export and spatial capacity#

The compact target accepts the existing Conv1d and MaxPool1d lowering through the ordinary compiler entrypoint. The transform maps temporal 1D geometry onto a height-one 2D representation and preserves its kernel, stride, padding, neurons and flatten order. Existing operator restrictions still apply.

compiled = spikepress.compile(
    model.eval(), example_input,
    bitstream="spikemold.bit",
)

The supplied Speech CNN checkpoint produces the same compact artifact as its explicit lower_1d path. Its previous board receipt binds that exact artifact.

Spatial placement also checks a necessary capacity bound before searching stage groups. The diagnostic reports output rows, vectors per row, maximum rows per tile and the minimum tile count against the qualified limit. The supplied Gesture LIF32 first layer has 128 output rows and 512 vectors per row. At 8192 vectors per tile it needs at least eight tiles, exceeding the current four-tile execution-plan limit. That unchanged model remains unsupported on this path. The compiler reports the bound before an unsuccessful placement search.
