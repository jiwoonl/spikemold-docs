Explicit C host operations#

Select allow_host_ops=True to capture supported fixed-shape host operations. The default follows source float32/float64 precision. Mixed precision, layouts, mutation and transitions back into binary event input have explicit checks.

Category

Operators

Synapses

Conv2d, Linear, eval BatchNorm2d

Pooling

MaxPool, AvgPool, AdaptiveAvgPool, sum, mean

Layout and merge

Reshape, transpose, fixed slice, concat, ADD, multiply, binary OR/AND

Activations

ReLU, sigmoid, tanh, Threshold

Classification

Mean, count, temporal and flatten readouts · Linear · softmax/top-k

Dynamic INT8

Conv and Linear · float32 output

Try the C float32 and INT8 examples. See execution details for exact capture, dtype, buffer and gradient restrictions. CPU native multi-step training is opt-in and supports first-order gradients; it is distinct from CUDA compiled recurrence.
