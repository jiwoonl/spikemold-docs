Choose a compatible deployment#

Use the same image bundle, model and preprocessing from export through board execution. Find the PYNQ-Z2 files in bitstreams/pynq-z2/.

Select the image#

Pass its filename to preflight, prepare, check, compile and connect. Keep the matching .hwh and .profile.json alongside the .bit. The SDK checks the bundle and selects its compiler/runtime profile; compilation reads the files without opening or programming a board. For example:

prepared, report = spikepress.prepare(
    model.eval(), example, bitstream="bitstreams/pynq-z2/spikemold.bit",
)
compiled = spikepress.compile(
    prepared, example, bitstream="bitstreams/pynq-z2/spikemold.bit",
)

Explicit target identifiers remain available for CPU-only exercises and compatibility. pynq-z2 selects the general v1 compiler contract; pynq_z2_spikemold_compact_v1 selects the compact package contract.

On PYNQ-Z2, connect with unmeasured_inference=True. Use program=True to load the overlay, or connect after loading it. See the board walkthrough.

Model and runtime limits#

Use binary event windows for PYNQ-Z2 inference. Export supported ADD graphs with compile_residual_add and apply the classifier through host readout. Compilation and board loading check the package geometry and image capacity. Use preflight to check fit before training. Supported operations lists the input and layer contracts.

An ordinary resident .spm loads as a validated package without reconstructing its training model. board.prepare_input(inputs) snapshots an input for the current Board and model load. Each call still transfers and executes; Count intermediates are recomputed. Reload, close or fault invalidates the handle. This optimization applies to admitted resident and Count paths, not all virtual or hybrid programs. Follow runtime recovery after faults.

For the standard path, decay_shift is 0–4. During authoring, decay="learnable" projects to the same values and prepare freezes the chosen shift.

The fractional candidate uses distinct retention codes 5–8. For example, use experimental_decay_code(0.75) to select code 5 when deriving a candidate from a validated compact v12 package with derive_fractional_candidate(base, codes). Supply one code per logical layer. The candidate loader checks the derived package and the image contract. Its integer reference approximates retention over an event gap with a Q6 coefficient and signed arithmetic rounding. Revalidate the integer golden and accuracy after changing a model’s retention.

>>> from spikepress.fractional_decay import experimental_decay_code
>>> [experimental_decay_code(beta) for beta in (0.75, 0.875, 0.9375, 0.96875)]
[5, 6, 7, 8]
