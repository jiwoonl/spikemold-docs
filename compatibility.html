Choose a compatible deployment#

Use the same image bundle, model and preprocessing from export through board execution. The included image trio is in bitstreams/pynq-z2/.

Select the image#

Pass its filename to preflight, prepare, check, compile and connect. Keep the matching .hwh and .profile.json alongside the .bit. The SDK checks the bundle and selects its compiler/runtime profile; compilation reads the files without opening or programming a board. For example:

prepared, report = spikepress.prepare(
    model.eval(), example, bitstream="bitstreams/pynq-z2/spikemold.bit",
)
compiled = spikepress.compile(
    prepared, example, bitstream="bitstreams/pynq-z2/spikemold.bit",
)

Explicit target identifiers remain available for CPU-only exercises and compatibility. pynq-z2 selects the general v1 compiler contract; pynq_z2_spikemold_compact_v1 selects the compact package contract.

On a compatible board, connect(bitstream=..., unmeasured_inference=True) uses the included image’s inference policy. program=True programs the image; the default is False and requires the matching overlay already loaded. The board walkthrough gives the complete first-run command.

Model and runtime limits#

The included image disables direct-current input, resident residual ADD/OR and weighted PL readout. Some bounded ADD models use host composition under a separate package contract. Package and runtime admission still check geometry and capacity. Gesture LIF32 needs at least eight tiles, exceeding the qualified maximum of four; compilation rejects it rather than rewriting the model. See supported operations for operator-level conditions.

An ordinary resident .spm loads as a validated package without reconstructing its training model. board.prepare_input(inputs) snapshots an input for the current Board and model load. Each call still transfers and executes; Count intermediates are recomputed. Reload, close or fault invalidates the handle. This optimization applies to admitted resident and Count paths, not all virtual or hybrid programs. Follow runtime recovery after faults.

Evidence to retain#

Item

Retain

Training

Architecture, checkpoint, preprocessing and input identities.

Export

Source revision, image, shape/T, preparation and compiler reports.

Package

.spm, input, golden, head and label identities.

Board

SDK/native and bitstream/HWH/sidecar identities, plus execution receipt.

Measurement

Input protocol, clock, wait policy, timing boundaries and raw receipt.

Recheck the relevant boundary after changing any of these assets. The included image uses inference-only operation with measurement_valid=false. A successful functional run does not establish PL-only timing, electrical energy or full-dataset FPGA accuracy. Measured results and the separate energy study state their own model, image and measurement scopes.
