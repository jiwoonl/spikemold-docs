Parameter reference#

This page summarizes the public controls used in the PyTorch guide, compilation API, and board runtime. Constructor acceptance does not guarantee that a model fits a target: use preflight, check, and compile, and inspect their reports. Shapes use batch B, timesteps T, channels C, length L, height H, and width W. Dimensions and strides are counts, not physical time units.

Native layers#

Conv1d/Conv2d are reset-zero IF layers; LIFConv1d/LIFConv2d add retention. Their canonical names are EventConvIF1d/EventConvIF2d and EventConvLIF1d/EventConvLIF2d. IFLinear and LIFLinear are the corresponding unit-spatial layers. Inputs are B,C,L or B,T,C,L for 1D; B,C,H,W or B,T,C,H,W for 2D. Linear supports B,T,C or B,C,1,1 or B,T,C,1,1. T must match the preset. State starts at zero on each forward call, persists across timesteps in that call, and resets to zero on a spike; independent calls do not carry state.

Parameter

Default

Meaning and constraints

in_channels, out_channels

required

Positive input/output channel counts.

in_features, out_features

required

Positive input/output feature counts for linear layers.

groups

1

Positive integer dividing both channel counts; selects grouped connectivity. Target-specific lowering may impose further limits.

kernel_size

3

Spatial kernel width (2D uses a square); only 1 or 3.

stride

1

Positive spatial step. Supported deployment geometry is target-dependent.

padding

0 (2D), None (1D)

Nonnegative spatial padding. In 1D, None selects 0 for K1 and 1 for K3; supported K/S/P triples are 1/1/0, 3/1/1, and 3/2/1.

initial_threshold

None

Positive finite floating-point starting value per output channel; None uses the preset’s value (normally 0.155). It initializes a learnable shadow parameter, not an INT16 code.

preset

None

SparseEventTrainingPreset; None constructs its defaults. Native layer construction requires its INT4 integer-aligned setting.

decay

None for LIF convolutions; required for LIFLinear

Finite retention beta in (0, 1], or "learnable". It multiplies the previous state, so 1 means IF/no leak. Convolutions require decay or decay_shift.

decay_shift

None

Exact integer 0–4; beta = 2^(-shift). If both numeric decay and shift are given they must agree. With decay="learnable", it sets the initial code (default 2).

Fixed beta need not be exactly representable during authoring, but must be lowered for deployment. Standard PYNQ-Z2 retention is 1, 1/2, 1/4, 1/8 and 1/16. Shift 0 is IF. The fractional candidate uses a separate package contract. Learnable decay uses a projected shift during forward and is frozen by preparation. Export computes each threshold code as clip(ceil(max(shadow, 1/256) / weight_scale), 1, 32767) in INT16. Preparation requires finite positive shadow thresholds; choosing a shadow value does not directly choose that integer code.

MaxPool1d and MaxPool2d (canonical EventMaxPool1d and EventMaxPool2d) accept kernel_size=2, stride=2, padding=0; each is a spatial count. The allowed K/S/P triples are 2/2/0, 3/1/1 and 3/2/1. 1D deployment lowering of K2/S2 requires an even input length. Their inputs use the corresponding 1D or 2D layouts above.

Threshold is the EventIF alias: channels is required and positive, and threshold=1 is an integer threshold in [1, 32767], replicated over channels. It compares BC or BCHW current and produces the input dtype’s 0/1 values. This is a T=1 helper, not the learnable per-channel threshold above.

The layer properties compile_multistep=False and native_multistep=False opt into optional training recurrence paths; collect_activity=True controls activity telemetry used by regularizers. Preparation and compilation#

preflight(model, example=None, *, target="pynq-z2", bitstream=None) reports early compatibility warnings; example is an optional representative tensor for shape/count capture. prepare(model, example, ...) requires a PyTorch model and example, makes an independent copy, and returns it with a report. Set model.eval() for deployment; preparation preserves mode and does not update an optimizer attached to the original. Normally the example is B,T,C,L or B,T,C,H,W with T in [1,64]. check(model, example_input, ...) reports compatibility, while compile(model, example_input, ...) performs exact admission and returns a path-dependent compiler result. Use representative fixed shapes; native event boundaries require binary events. Compilation does not itself program a board.

Parameter

Default

Meaning and constraints

target

"pynq-z2"

Target/profile name. Public default uses the release target; explicit profile support and capacity depend on the operation.

bitstream

None

Path to a bitstream used to resolve a verified profile; choose a matching target and package.

validate (prepare)

True

Boolean. False skips compiler compatibility and count capture; compile still must succeed.

model_id (compile)

None

Optional model identifier for the compiled artifact.

policy (compile)

"compatible"

"compatible" or "efficient" placement policy; inspect the resulting report.

result_mode (compile)

"events"

"events" or "channel_count"; supported result modes depend on target/path.

Advanced preparation and compatibility#

prepare uses policy=None by default. policy="strict" requires exact decay; policy="adapt" projects to the nearest shift in log2 space and requires a finite nonnegative max_decay_error absolute tolerance on beta. max_decay_error is invalid with strict policy. Adaptation also rejects a beta below 1 if its nearest shift is 0 (IF), even within tolerance. The explicit IF-conversion route uses the legacy preparation options decay_quantization="nearest_log2", max_decay_abs_error=..., allow_if_conversion=True; it cannot be combined with policy. Do not combine either policy with the legacy controls below. Review the returned per-layer decay report: adaptation changes retention and may require retraining or validation.

Parameter

Default

Meaning and conflicts

decay_quantization

"exact"

"exact" or "nearest_log2"; the latter explicitly projects to the shift codebook.

max_decay_abs_error

None

Required finite nonnegative absolute beta error bound with nearest_log2; forbidden with exact.

allow_if_conversion

False

Boolean; permits a beta below 1 to project to shift 0 (IF).

temporal_stage_groups (compile)

None

Optional 1–4 (first, last) groups: zero-based, inclusive, ordered, contiguous and nonempty; together they cover every logical layer and must meet the selected per-stage limit. Omit for automatic placement. Rejected on ambiguous virtual/flatten cuts.

For the public target, compile requires exact decay and rejects the legacy adaptation options; adapt with prepare first. prepare does not silently change trained weights or thresholds.

Optional host operations#

The following options are shared by prepare, check, and compile:

Parameter

Default

Meaning and constraints

allow_host_ops

False

Explicitly permits supported C host operations and PL islands. Hybrid compilation requires exact event semantics, result_mode="events", and automatic grouping; decay adaptation and explicit groups conflict.

host_precision

None

With host ops, "float32" or "float64"; inferred as float64 for a float64 example, otherwise float32. Explicit selection is needed for mixed source precision. Host precision does not alter the PL INT4/INT16 numeric grid.

input_domain

None

With host ops, "binary" or the selected host precision string. Inferred as binary for bool examples or direct native ingress, otherwise host precision. Binary means 0/1 inputs.

max_workspace_bytes

67108864

Hybrid peak live-tensor + parameter + INT8 scratch budget in bytes, integer 1 through 67,108,864. Excludes JSON, PL images, DMA and separately bounded kernel scratch; not total process/board memory.

host_precision and input_domain require allow_host_ops=True. The hybrid path expects a fixed-shape float32, float64 or bool example and an eval-mode model. Actual supported operators and boundaries remain subject to compiler admission.

Weight storage#

Native IFLinear/LIFLinear reuse a 1x1 convolution and store weights as [out_features,in_features,1,1], not the two-dimensional storage of torch.nn.Linear. Preserve this shape in checkpoints or explicit assignment. Matching shapes alone does not qualify a pretrained float model’s conversion.

Runtime and artifacts#

load(path) reads and validates a saved .spm artifact; path is required. It returns an artifact/program, not the original training model. board.load(compiled) accepts a compatible compiled object or artifact path and invalidates prepared input handles. See runtime and compatibility.

connect parameter

Default

Meaning and constraints

target

"pynq-z2"

Public target or a supported explicit compatibility profile.

bitstream

None

Bitstream path; otherwise SPIKEPRESS_BITSTREAM or profile default is used. Profile and loaded artifact must match.

program

False

Explicitly request programming the image when true. Supplying a bitstream path alone does not program it; CLI --program is likewise an explicit action.

transport

None

Optional existing transport; cannot be combined with bitstream or program=True. Configure its wait policy on the transport itself.

native_library

None

Optional diagnostic native library path; normally discovered automatically (explicit use is deprecated).

input_slot_count

1

Must be 1; release batch runner manages slots.

wait_policy

"latency"

"latency", "balanced", "interrupt", or "auto"; affects waiting behavior, not a speed or energy guarantee. A supplied transport requires the default here.

session_cookie_path

None

Reserved; no currently accepted public connection policy permits a non-None path.

unmeasured_inference

False

True for PYNQ-Z2 functional inference.

board.prepare_input(value) takes an unprepared input tensor for the loaded model and snapshots it for repeated runs. Handles belong to that board and loaded model; reload, close, or fault invalidates them. Some virtual and hybrid programs do not support this facility. board.run(value, *, window_tag=None, readout=None) accepts a compatible input or owned prepared handle. window_tag is an optional integer in [0, 65535]; None auto-increments with wraparound. readout is an optional supported native classifier readout; hybrid programs carry their own explicit readout and reject it. Supported batches return multiple results; consult the runtime API for streaming and batch methods.

Residual ADD export#

compile_residual_add(model, example_input, *, target="pynq-z2", bitstream=None) accepts the explicit integer temporal ADD graph described in residual addition. model must be in eval mode and its weights/thresholds must satisfy that graph’s integer contract. example_input is one binary B,T,C,H,W window. target retains the existing default; bitstream selects its verified image profile and rejects conflicting metadata. It does not convert an arbitrary training model or program an FPGA.

Input and terminal helpers#

EventReadout() has no constructor parameters; its inputs must be a BCHW or BTCHW tensor, returned unchanged. pack_event_features(inputs) accepts BCHW and returns contiguous B,C×H×W,1,1 in row-major order; it does not infer or add a timestep. See input layouts and native layers.

Training progress#

Training reports explain log interpretation and limits. TrainingMonitor is opt-in and reports caller-supplied values; it does not compute training statistics or prove completion.

Call and parameter

Default

Meaning and constraints

TrainingMonitor(every=...)

50

Positive integer step interval. The first observed step of each epoch and the final step are also emitted.

stream

None

Writable text stream for progress; None selects standard error.

log_path

None

Optional new JSONL file path; an existing file is rejected. Close the monitor or use it as a context manager.

update(epoch, step, total_steps=None, **metrics)

required epoch, step

Nonnegative integer epoch and step; optional positive integer total_steps must be at least step. Named metrics must be finite numeric scalars when emitted; skipped steps do not inspect metrics. Returns whether it emitted a snapshot.

summary(*, epoch, **metrics)

required epoch

Nonnegative integer epoch and caller-computed finite scalar metrics; no averaging is performed.

phase(name)

required

Nonempty string naming a context-managed host interval; records completion/failure and wall seconds without synchronizing devices. Overlapping intervals are not additive.

report_hardware(report, *, compilation=None)

required report

Existing preflight report and optional compilation report for formatting/recording; this does not compile or execute hardware.

summarize_training_log(path)

required

Path to a JSONL log. Limits are 16 MiB per file and 1 MiB per line; invalid or incomplete records raise an error. Last entries are by file order and completion remains unknown.

Host readout#

The functions below consume output, a sequence of terminal spike records or a result mapping. The caller supplies model metadata, including silent channels; see host classification. A channel-count result has no temporal records, so first_spike rejects it. The other supported reductions follow the count payload’s own denominator where applicable.

Call and parameter

Default

Meaning and constraints

spike_count(output, *, channels, timesteps)

required

Per-channel count over the window. For record reduction, channels is 1–1024 and timesteps is 1–64.

spike_rate(output, *, channels, timesteps)

required

Per-channel count divided by T for records; a channel-count payload uses its declared denominator. This need not be a spatial mean.

first_spike(output, *, channels, timesteps)

required

Earliest timestep per channel, or None if silent; record path has the same bounds above.

population_count(output, *, classes, timesteps)

required

classes maps each channel to a nonnegative integer class index; counts are summed by index. For record reduction, each index must be below the number of channels.

global_average(output, *, timesteps, output_shape_hwc, state_base, state_limit)

required

Time/spatial mean per channel. output_shape_hwc is (H,W,C); state_base and state_limit are the terminal layer’s declared state address bounds.

linear(output, weight, bias=None, *, timesteps, output_shape_hwc, state_base, state_limit)

bias=None

Applies a host linear head to the preceding mean. weight is finite numeric [classes,C], bias is absent or finite [classes].

Classifier(head) owns a float64 copy of the finite numeric arrays in its required mapping. Its weight is [classes,features], bias is [classes], and mode defaults to "mean"; supported modes are "mean", "count", "temporal", and "flatten". Temporal mode requires temporal_weights of length T, nonnegative and summing approximately to one. Flatten mode accepts time_bins=1 and optional grid (default: full output H,W); positive bin/grid sizes cannot exceed the corresponding output dimensions. Feature width must match the selected reduction and output geometry. Temporal and flatten modes reject channel-count results. Pass the classifier to a compatible board.run(..., readout=classifier); this head runs on the host.

Event applications#

encode_events(events, preprocessing, *, native_library=None) converts raw events to binary uint8 [1,T,C,H,W] using the C extension, with no Python numerical fallback. events is numeric [N,4] in [time,y,x,channel] order; coordinates must be finite, integer-valued and in bounds, and timestamps must lie in the declared window. Integers must be exactly representable in float64. Duplicate events in a bin combine by OR; the encoder does not crop or silently discard events. native_library=None discovers the installed extension; an explicit path selects a library. See input encoding.

The required preprocessing mapping has exactly these keys:

Key

Meaning and constraints

encoding

Must be "uniform_binary_or".

window_start, window_end

Finite scalar endpoints in the caller’s common timestamp unit, with start < end; bins cover the half-open interval [start,end). Integer endpoints must be within ±2^53.

timesteps

Integer T in [1,64]; uniform time bins.

shape_hwc

Three positive integers [H,W,C]; output is limited to 64 MiB. For application export it and T must match the artifact.

export_deployment(artifact, destination, *, head_weight, head_bias, labels, preprocessing, reduction="mean", time_bins=None, grid=None, temporal_weights=None) writes a new application directory. artifact is an existing compatible .spm path and destination must not exist. Application export accepts v12 binary event packages with terminal spike records. head_weight is a finite numeric [classes,features] matrix, head_bias a finite [classes] vector, and labels a list or tuple of distinct nonempty strings, one per class. The head is stored as float64. preprocessing is the mapping above and must match the artifact input.

Reduction option

Default

Meaning and constraints

reduction

"mean"

"mean", "count", "temporal", or "flatten"; see deployment for the exact feature definitions.

time_bins

None

Required for flatten: integer 1–T. Must be omitted for other modes.

grid

None

Required for flatten: [height,width] positive integers no larger than terminal H,W. Must be omitted for other modes. Flatten feature width is time_bins×C×grid height×grid width; other modes use C.

temporal_weights

None

Required for temporal: finite nonnegative length-T vector whose sum differs from 1 by at most 1e-5. Must be omitted for other modes.

Deployment(directory, *, native_library=None) validates application assets at the required directory path; the optional library path selects the C extension. app.encode(events) uses the bound preprocessing. app.load(board) explicitly loads this application on a Board; reloading a different model invalidates the binding. app.run(board, events, *, window_tag=None, postprocess=None, top_k=None) encodes raw events and runs on that loaded board. app.classify(words, *, window_tag, postprocess=None, top_k=None) instead validates a complete raw result frame; words are raw frame words, not a Board.run result mapping, and window_tag is required. The run tag defaults to the Board’s automatic tag; explicit tags are uint16. postprocess is None or "softmax"; top_k is None or an integer from 1 through the class count. Top-k scores use probabilities when softmax is requested and logits otherwise. These options require C host kernels. app.report() takes no arguments and describes the bound application; its hardware qualification remains NOT_CHECKED.
