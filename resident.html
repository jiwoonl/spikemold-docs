Packages and model loading#

Use prepare → compile → save → load to export and inspect supported event models, then load the package into a compatible board session. A .spm is a deployment artifact; use a training checkpoint to resume optimization.

Save, inspect and load#

python examples/compile_model.py --bitstream bitstreams/pynq-z2/spikemold.bit \
  --output runs/package-example
python -m spikepress.cli inspect runs/package-example/model.spm

import spikepress

package = spikepress.load("runs/package-example/model.spm")

An ordinary resident package loads as a validated mapping. It does not recreate the original training or compiler object. Hybrid/virtual programs have their own interfaces; see the API.

Stage

Behavior

save

Writes a new artifact and refuses to replace an existing path.

load / inspect

Rejects malformed containers, duplicate JSON fields, nonfinite values, changed hashes and incompatible package contracts. Does not access a board.

connect

Selects/verifies image metadata; expects the overlay already loaded unless program=True.

Board.load

Checks package/image compatibility and physical limits before model use.

prepare_input

Creates an owned snapshot for that Board and model load; each run still executes freshly.

Use the same image trio and preprocessing at export and execution. The included image is available under bitstreams/pynq-z2/; actual board setup is described in the walkthrough.

Ownership and failure handling#

A validation failure before publication does not by itself establish a device fault. A failure after device configuration or DMA publication may leave ownership uncertain and latch a fault. Do not assume that close, reload or retry proves that a transfer has drained. Retain quarantined allocations and follow runtime recovery.

A board session has one controlling thread. Explicit window tags must be Python integers in 0–65535; explicit batch tags must have matching length and be unique. Closed sessions reject runs and reloads. Successful close is not a general fault-recovery procedure.

Compatibility and qualification#

Application bundles add preprocessing, a host head and labels. The runtime still uses Python orchestration around C kernels and DMA calls; it is not an all-C driver. Software checks do not establish new board, electrical-energy or task-accuracy results. Read the support matrix, measured performance and deployment boundaries.

Older fixed-geometry parameter exporters have different image and model contracts. Their existing entrypoints remain documented in the developer legacy exporter reference; they are not the normal user deployment path.
