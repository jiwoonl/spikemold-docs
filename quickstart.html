Compile your first SNN#

This example runs entirely on a CPU. It creates a tiny native shift-LIF network with a nonzero binary input, compares PyTorch with an integer golden, and saves and reloads a deployment package. It does not connect to a board.

Follow the workstation installation guide to install PyTorch and SpikePress. Either the CUDA wheel or the CPU wheel can run this example.

Run the complete example first#

After installation, from the repository root:

python examples/compile_model.py --output runs/first-compile
python -m spikepress.cli inspect runs/first-compile/model.spm
python -m json.tool runs/first-compile/validation.json

The older compile_model.py example only printed a package hash; it now requires --output and saves inspectable files. Use a new output directory. The example prints these stable fields:

{"status": "PASS_CPU_GOLDEN", "input_shape": [1, 2, 8, 8], "golden_shape_thwc": [2, 1, 4, 8], "nonzero_output_spikes": 1, "compiler_accepted": true, "hardware": "NOT_CHECKED"}

It writes model.spm, events.npy, golden.npy, preflight.json, preparation.json, compiler_report.json and validation.json. events.npy is the nonzero binary input; golden.npy is the exact host integer output. Inspecting a package does not execute hardware. Below is the same model and export process, step by step.

1. Author a temporal model#

The input layout is B,T,C,L: batch, timesteps, channels, length. This model uses two timesteps and length eight. The weights and input are fixed so the example exercises a nonempty output rather than only silent spikes.

import json
from pathlib import Path
from tempfile import TemporaryDirectory

import numpy as np
import torch
import spikepress
from spikepress.nn import LIFConv1d, MaxPool1d
from spikepress.sparse_event_training import SparseEventTrainingPreset

torch.manual_seed(7)
model = torch.nn.Sequential(
    LIFConv1d(8, 8, kernel_size=3, decay_shift=1,
              preset=SparseEventTrainingPreset(timesteps=2)),
    MaxPool1d(kernel_size=2),
).eval()
with torch.no_grad():
    model[0].weight.zero_()
    model[0].weight[0, 0, 1] = 1
    model[0].threshold.fill_(1)

events = torch.zeros(1, 2, 8, 8, dtype=torch.float32)
events[0, 0, 0, 2] = 1

State carries across the two timesteps within one forward call and resets between calls. Passing each timestep through a separate call would change the model’s temporal behavior. See PyTorch authoring.

2. Prepare and compile#

prepare copies the model and binds its timestep configuration. Skip its compiler validation here because the following compile performs acceptance checks. The included bitstream bundle selects the accepted compiler profile and its temporal golden interface. Reading these files does not connect to a board.

bitstream = "bitstreams/pynq-z2/spikemold.bit"
prepared, report = spikepress.prepare(model, events, bitstream=bitstream, validate=False)
assert report["compatibility"]["status"] == "NOT_RUN"
compiled = spikepress.compile(prepared, events, bitstream=bitstream)
assert compiled.rejection_report["accepted"] is True

Use preflight before costly training and inspect the exact compiler rejection when a graph is unsupported. A warning about a possible tiling or pruning strategy does not mean that strategy has been applied.

3. Compare the integer golden and reload the package#

Generate the host golden from the compiler object before saving. A loaded resident .spm is a validated package mapping, not the original compiler object. save refuses to overwrite an existing artifact; this example uses a fresh temporary directory.

input_package = compiled.compile_input(events)
with torch.no_grad():
    expected = prepared(events).numpy()[0].transpose(0, 2, 1)  # T,L,C
golden = input_package.expected_spikes_thwc[:, 0]  # T,H=1,L,C -> T,L,C
assert np.count_nonzero(expected) > 0
np.testing.assert_array_equal(golden, expected)

with TemporaryDirectory(prefix="spikepress-quickstart-") as directory:
    artifact = spikepress.save(compiled, Path(directory) / "model.spm")
    loaded = spikepress.load(artifact)
    assert loaded == json.loads(json.dumps(compiled.package))

print("CPU compile, package reload and integer golden: PASS")

CPU compile, package reload and integer golden: PASS

This establishes host agreement for this model and input. It is separate from RTL simulation or execution on an FPGA. When exporting your own model, save the package, matching input, golden, model configuration and source identities to a new persistent directory.

4. Train or deploy#

The verified bitstream, HWH and sidecar come with git clone/git pull under bitstreams/pynq-z2/. Pass this same filename through preparation and compilation, then use the same repository revision on the board:

prepared, report = spikepress.prepare(
    model, events, bitstream="bitstreams/pynq-z2/spikemold.bit", validate=False,
)
compiled = spikepress.compile(prepared, events, bitstream="bitstreams/pynq-z2/spikemold.bit")

These deployment snippets use the included qualified bundle and run on CPU. The SDK selects the profiles from verified metadata, so ordinary deployment does not require an internal revision ID.

For a small optimizer-loop demonstration from the source checkout:

python examples/training_workflow.py --output /tmp/my-first-spikepress-run
spikepress training-report /tmp/my-first-spikepress-run/training.jsonl

The output directory must be new. This performs four synthetic CPU updates; it is an API demonstration rather than an accuracy benchmark. See training for checkpoints, resumption and execution controls.

For hardware execution, first choose the matching image and profile and follow board installation. The generic compiler target and a connection to the included image have different admission contracts. Preparing or compiling this example does not establish that an arbitrary loaded image can execute it.
